# v304 steam-era sailor uniform

Installed through the common repair-sailor initialization only when the ship definition is SteamPowered. Both player and enemy crews receive the outfit; sail-era models are unchanged. Native body renderers use navy cloth/neutral head/dark boot materials. Head-bound white cap and a torso-bound white V collar with neckerchief distinguish the sailors. Accessories have no colliders; the native robot body, injury and animation system remain active. Native weapon models are hidden, while independent bucket/plank/spare-part work visuals remain available.

This is a cosmetic skin, not a replacement native character class. Assembly compilation verified; no live visual or animation QA has been performed. Native melee AI has not been redesigned into an unarmed fighting system.
