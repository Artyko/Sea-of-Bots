# v325 — опора матросов и разбор потери хода Novik

Последний доступный Player.log помечен v323; он не проверяет установленные после этого изменения v324. В конце: инженеры 0, мощность 0,18, котлы 1/3/5 без топлива и давления, котлы 0/2/4 с давлением 0,55, первый вал/винт с целостностью 0,93. Ранее при двух инженерах, ещё целых валах и трёх работающих котлах мощность была около 0,48. То есть спад складывается из нескольких отказов, а не только исчезновения дыма одной трубы. Нулевое топливо трёх нечётных котлов соответствует их общей топливной ветви; прежняя телеметрия не записывала состояние баков, поэтому точную историю повреждения бака по этим строкам восстановить нельзя. Точную скорость 1 узел нельзя вывести из этих строк без фактической установки телеграфа и остальных ограничений движения.

Исправления:
- Гравитация для неподдерживаемого матроса применяется при каждом обычном Tick, включая ожидание и работу, а не лишь в отдельных ветках восстановления. Принадлежность прямоугольнику трапа больше не заменяет физическую опору. Перемещение к более высокой точке не поднимает матроса без подтверждения опоры у следующей точки; плавание и прыжок сохраняются.
- Непрерывность вала проверяется отдельно от лопастей винта. Обрыв линии вала по-прежнему отключает её ветвь; частично повреждённый винт снижает тягу пропорционально целостности, а не отключает всё сразу. Турбины и давление остаются необходимыми.
- Альтернативные подходы к помпе вычисляются относительно её положения, в метрах. Старая логика перезаписывала x абсолютными локальными 0/±0,55, теряя положение смещённой помпы.
- В журнал энергетики добавлены телеграф, оба топливных бака, обе магистрали, тяжесть утечки пара и непрерывность каждой линии вала. Эти данные отделяют отсутствие давления, потерю топлива, механический обрыв и команду малого хода.

Проверки прошли: Naval325Checks, Naval324Checks, NovikChecks (1156 маршрутов), SteamCombatVitalityChecks, StairCapsuleTravelChecks (модель контактной капсулы, не нативный PhysX). Сборка успешна. Нативный запуск не выполнялся по просьбе пользователя. Доказательства отсутствия всех остановок на повреждённых кораблях нет; следующий бой должен проверить поведение в игре.
