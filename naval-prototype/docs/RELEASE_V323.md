# v323 — смена задачи на трапе и четыре торпедиста

Последний лог версии 322 содержит повторяющиеся остановки Novik около (±0,44; 0,60–0,66; -2,32/+2,56). Цель маршрута при этом находится сразу на полу трюма (Y=0,15) сбоку от ступеней. Есть повторные восьмисекундные watchdog-события. Механизм: задача меняется, пока матрос на наклонном трапе; новый маршрут ошибочно начинает боковой участок на уровне нижнего пола.

Маршрутизатор эсминца теперь распознаёт фактическое положение на одном из четырёх трапов, продолжает ступени вверх либо вниз до нужной площадки и только затем строит остальной путь. Подлестничное восстановление остаётся отдельным: нельзя считать матроса под трапом стоящим на его поверхности. Коллизии ступеней и палуб не отключаются.

Назначение торпедистов расширено с двух до четырёх независимых рабочих слотов, по одному на доступный аппарат; дублирование аппарата исключает существующая проверка назначения. Наличие двенадцати матросов сохраняется. При потерях экипажа или критической аварии возможен временный недокомплект; оператора не заменяет дистанционная стрельба.

Локальные проверки: Naval323Checks (24 комбинации смены задачи на четырёх трапах, оба направления, три высоты), NovikChecks, Naval322Checks, StairTrafficChecks, Naval319Checks, CrewWorkAccessChecks, TorpedoReloadChecks. Нативный игровой запуск не выполняется по просьбе пользователя. Лог также содержит остановки противника и отдельных повреждённых маршрутов; исправление выявленного дефекта не является подтверждением отсутствия всех возможных застреваний.
